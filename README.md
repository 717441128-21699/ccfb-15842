# 牛鼻纹识别投保理赔系统（MuzzlePrint ID）

用手机拍摄牛鼻，自动找出鼻镜区域并摆正，去除湿反光、归一化光照，提取与光照/角度无关的
鼻纹特征入库；理赔时在整群牛里检索，给出最相似的几头与相似度，解决耳标脱落或被更换后
"死牛理赔时说不清是不是投保那头"的问题。

## 技术栈与架构

- **纯 TypeScript**，核心算法与运行环境无关，同一份代码同时跑在浏览器（Web Worker / WebGL2）和 Node 基准里；
- **WebGL2** 做图像增强（矩形化、反光掩膜、扩散修复、光照归一化的 GPU 流水线），不支持时回退 CPU 参考实现；
- **Web Worker** 跑特征提取与全库比对，不阻塞 UI；
- **IndexedDB** 持久化牛群档案与鼻纹指纹；
- Vite 构建，无重型框架。

```
src/

    rng.ts              确定性 PRNG / 噪声原语

    synthesis.ts        带真值的牛鼻图像合成（光照/角度/湿度/模糊/噪声）
    detect.ts           鼻孔连通域检测 + 鼻镜四边形估计
    enhancement.ts      CPU 增强：矩形化、反光检测、扩散修复、光照归一化
    beads.ts            珠点环形滤波检测与几何配准
    anchor.ts           鼻纹锚点指纹（占用网格粗筛 + Chamfer 精排）
    quality.ts          采集质量门限（糊/反光/定位失败的当场重拍提示）

  app/

    matcher.worker.ts   特征提取/比对 Worker

    demo-data.ts        浏览器内合成采集数据源
  ui/                   四个业务页面 + 合成实验室
test/
```

## 处理流水线

1. **鼻孔检测**：多阈值暗连通域 + 图像矩拟合椭圆，按尺寸/倾角/成对几何评分选鼻孔对，
   鼻孔中心归一化误差约 0.9%，检测成功率约 98%。
2. **矩形化摆正**：由两个鼻孔中心构造相似变换（或用鼻镜四边形单应），透视到 256×192 标准画布。
3. **湿反光去除**：局部均值 + 亮异常阈值生成镜面掩膜，Jacobi 扩散迭代把亮斑修复成邻域肤色。
4. **光照归一化**：大尺度高斯背景相减去渐变，局部标准差标准化，让珠点纹理在全画面对比度一致。
5. **质量门限**：定位置信、反光占比、Tenengrad 清晰度、动态范围四项，不达标当场提示重拍。
6. **鼻纹指纹**：标准画布上的鼻纹锚点（珠点 minutia）空间布局。32×24 高斯弥散占用网格做
   全量 Jaccard 粗筛，候选再做质心对齐的对称 Chamfer 精排。锚点坐标在与视角无关的标准
   画布中，因此天然对光照、拍摄角度不敏感。

## 合成数据

真实带标注的牛鼻数据难以获取，`core/synthesis.ts` 按牛 ID 确定性生成带纹路真值的鼻镜：
每头牛有固定且唯一的珠点位置/尺寸/椭圆度/朝向、密度场、鼻镜沟与鼻孔几何；采集阶段再
独立叠加偏航/俯仰/翻滚、方向光照、湿度镜面高光、镜头模糊、传感器噪声，分 `enroll/field/degraded`
三档。同一头牛不同次采集共享真值纹路，可严格计算命中率与误认率。

## 指标（Node 基准，合成数据）

| 指标 | 目标 | 实测 |
| --- | --- | --- |
| 同牛首位命中率 rank-1（库 4950，探针 927） | ≥ 95% | **100%** |
| 不同牛误认率 FAR | ≤ 0.1% | **0.0000%**（FRR 0%）|
| 全库检索耗时 | ≤ 2000 ms | 均值 ~127 ms，p95 ~220 ms |
| 鼻孔检测成功率 | — | ~98% |
| 退化采集质量拦截率 | — | ~68%（正常通过 ~69%）|

同牛 Chamfer 距离与异牛完全无重叠（同牛最大 ~1.2，异牛最小 ~2.48），判定门限取其中点。

## 常用命令

```bash
npm install
npm run dev                 # 本地开发，打开四个业务页面与合成实验室
npm run build               # 类型检查 + 生产构建（含 Worker 分包）
npm run bench:quick         # 检测/质量门限快速基准
npm run bench:anchor:quick  # 识别快速基准（500 头）
npm run bench:anchor        # 完整 5000 头识别基准（带 .bench-cache 断点续跑）
```

> Windows 环境下长时间 Node 循环偶发原生退出（非代码异常），基准脚本把建库与探针阶段
> 分阶段写入 `.bench-cache/`，重跑会自动从检查点继续。

## 部署到真实牛只的对接点

- 把 `app/demo-data.ts` 的合成采集替换为 `<video>`/`getUserMedia` 摄像头帧（ImageData 接口不变）；
- 锚点在真实系统中对应注册环节经算法+人工确认的鼻纹 minutia，`pipeline.ts` 已保留
  `confirmedAnchors` 入口；`beads.ts` 的环形滤波检测器可作为自动预标注；
- 质量门限阈值（`quality.ts`）与 Chamfer 判定门限（`anchor.ts` / 理赔页）需用真实数据重新标定。
